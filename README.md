# Retail Sales Analytics Pipeline

An end-to-end data engineering project built with PostgreSQL, Docker,
dbt, and Python.

## Project objectives

- Load retail CSV datasets into PostgreSQL using dbt seeds.
- Transform raw data into analytics-ready models with dbt.
- Validate data quality with automated tests.
- Build reproducible and documented transformations.
- Query sales and product performance using SQL.

## Architecture

CSV files → PostgreSQL → dbt transformations → Analytics tables

## Technology stack

- PostgreSQL
- Docker
- dbt Core
- dbt-postgres
- Python
- Git and GitHub
